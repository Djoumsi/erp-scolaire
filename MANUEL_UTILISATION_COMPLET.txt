INTRODUCTION
───────────────────────────────────────────────────────────────────────────

1.1 QU'EST-CE QUE L'ERP SCOLAIRE CAMEROUN ?

L'ERP Scolaire Cameroun est une solution informatique complète conçue pour
simplifier la gestion administrative et pédagogique des établissements
scolaires (écoles primaires, collèges, lycées et universités).

Avantages principaux :
• Gestion centralisée de tous les données scolaires
• Économies de temps et d'argent
• Amélioration de la communication école-parents
• Suivi automatisé des notes et présences
• Génération rapide des rapports et statistiques
• Sécurité des données avec sauvegarde automatique
• Accès depuis n'importe quel navigateur web

1.2 CONFIGURATION REQUISE

Matériel :
• Ordinateur de bureau ou portable
• Connexion Internet stable (au minimum 1 Mbps)
• Navigateur web moderne (Chrome, Firefox, Safari, Edge)

Logiciels :
• Aucun logiciel supplémentaire à installer
• L'application fonctionne entièrement en ligne

Recommandations :
• Utiliser une connexion sécurisée (HTTPS)
• Mettre à jour votre navigateur régulièrement
• Avoir une sauvegarde des données importantes

1.3 AVANT DE COMMENCER

Préparation préalable :
1. Identifiants : Demander au directeur votre identifiant et mot de passe
2. Rôle : Connaître votre rôle dans l'application
3. Formation : Participer à la séance de formation (webinaire ou présentiel)
4. Documentation : Avoir ce manuel à portée de main

Les différents rôles :
• Super Admin : Accès complet à toute l'application
• Admin : Gestion de l'établissement et des utilisateurs
• Directeur : Supervision générale et rapports
• Enseignant : Saisie des notes et gestion des présences
• Comptable : Gestion des paiements et finances
• Secrétaire : Support administratif

2.3 GESTION DU PROFIL UTILISATEUR

Accéder à son profil :
1. Cliquer sur votre avatar (en haut à droite)
2. Cliquer sur « Mon profil »

Informations disponibles :
• Nom complet
• Fonction/Rôle
• Établissement
• Photo de profil
• Adresse email
• Numéro de téléphone

Modifier votre profil :
1. Cliquer sur « Modifier »
2. Remplir les champs à jour
3. Cliquer sur « Enregistrer »

Changer le mot de passe :
1. Aller à « Mon profil »
2. Cliquer sur « Changer le mot de passe »
3. Entrer l'ancien mot de passe
4. Entrer le nouveau mot de passe (2 fois)
5. Cliquer sur « Mettre à jour »

Recommandations pour le mot de passe :
• Minimum 8 caractères
• Mélanger majuscules, minuscules, chiffres, symboles
• Ne pas utiliser d'informations personnelles
• Changer tous les 3 mois
• Exemple : SchL@2024!Cameroun

GESTION DES ÉLÈVES
───────────────────────────────────────────────────────────────────────────

4.1 INSCRIPTION D'UN ÉLÈVE

Première étape : Cliquer sur « Élèves » dans le menu de gauche

Bouton « + Inscrire un élève »

Remplir le formulaire :

INFORMATIONS PERSONNELLES
├─ Nom complet * (obligatoire)
├─ Prénoms * (obligatoire)
├─ Date de naissance * (obligatoire)
├─ Sexe * (Masculin / Féminin)
├─ Lieu de naissance
├─ Nationalité
└─ Numéro d'identité (si disponible)

CONTACTS
├─ Adresse résidence
├─ Téléphone parent
├─ Email parent
└─ Contact d'urgence

INFORMATIONS SCOLAIRES
├─ Classe * (2nde A, 1ère D, Tle C, etc.)
├─ Ancien établissement
├─ Redoublement (Oui / Non)
└─ Observations

PHOTO
└─ Télécharger une photo (JPG, PNG - max 5 Mo)

Points importants :
✓ Les champs avec * sont obligatoires
✓ Vérifier l'orthographe du nom
✓ Utiliser la date au format : JJ/MM/AAAA
✓ Une photo nette facilite l'identification
✓ Sauvegarder régulièrement

Après remplissage :
1. Cliquer sur « Inscrire »
2. L'élève reçoit un matricule unique (ex: LMA2026060)
3. Message de confirmation affichée
4. L'élève apparaît dans la liste

4.2 MODIFICATION DES INFORMATIONS

Pour modifier un élève :
1. Aller à « Élèves »
2. Trouver l'élève (recherche ou défilement)
3. Cliquer sur l'icon MODIFIER (crayon) à droite
4. Mettre à jour les informations
5. Cliquer sur « Enregistrer »

Historique conservé :
- Toute modification est enregistrée
- Responsable identifiée
- Heure et date mémorisées

Suppression d'un élève :
⚠️ Non recommandé (perte de données historiques)
→ Utiliser plutôt : « Archiver » l'élève
→ Accès : Icon poubelle (rouge) à droite

4.3 IMPORT EN MASSE (CSV)

Gestion rapide de plusieurs élèves

Accès :
1. Aller à « Élèves »
2. Cliquer sur « Importer en masse »

Étapes :

1. TÉLÉCHARGER LE MODÈLE
   → Cliquer « Télécharger le fichier CSV »
   → Ouvrir dans Excel ou LibreOffice Calc

2. REMPLIR LE FICHIER
   Colonnes requis :
   nom,prenoms,date_naissance,sexe,classe

   Exemple :
   ┌──────────────┬──────────────┬──────────────┬───────┬──────────┐
   │ nom          │ prenoms      │ naissance    │ sexe  │ classe   │
   ├──────────────┼──────────────┼──────────────┼───────┼──────────┤
   │ DIALLO       │ Aminata      │ 10/05/2008   │ F     │ 2nde A   │
   │ KONATÉ       │ Ibrahim      │ 23/03/2008   │ M     │ 2nde A   │
   │ SANOGO       │ Mariam       │ 15/07/2009   │ F     │ 1ère D   │
   └──────────────┴──────────────┴──────────────┴───────┴──────────┘

3. ENREGISTRER EN CSV
   Format : UTF-8
   Délimiteur : Point-virgule (;)

4. IMPORTER DANS ERP
   → Cliquer « Sélectionner le fichier »
   → Choisir le fichier CSV
   → Cliquer « Importer »

5. VÉRIFICATION
   → Liste des élèves importés
   → Nombre ajouté/erreur signalée
   → Corriger les erreurs et réessayer

Erreurs courantes :
❌ Format date incorrect → JJ/MM/AAAA
❌ Classe inexistante → Vérifier l'orthographe
❌ Nom vide → Tous les champs requis obligatoires
❌ Fichier ne se charge pas → Vérifier le codage UTF-8

4.4 EXPORT DES DONNÉES

Exporter la liste complète :
1. Aller à « Élèves »
2. Cliquer sur « Exporter » (icone Excel)
3. Choisir le format :
   ✓ Excel (.xlsx) - Recommandé
   ✓ CSV (.csv) - Pour d'autres applications

Le fichier inclut :
• Matricule
• Nom et prénoms
• Date de naissance
• Sexe
• Classe
• Statut (Actif/Archivé)
• Date d'inscription
• Contact parent
• Et 10 autres informations

Le fichier télécharge automatiquement sur votre ordinateur.

5.3 GESTION DES DROITS D'ACCÈS

Chaque utilisateur a un rôle avec permissions définies.

Hiérarchie des rôles :

1. SUPER ADMIN
   → Accès complet à tout
   → Gestion des établissements
   → Création de tous les comptes
   → Sauvegardes système

2. ADMIN ÉTABLISSEMENT
   → Gestion personnel + élèves
   → Configuration classes
   → Rapports complets
   → Sauf : aspects financiers critiques

3. DIRECTEUR
   → Consultation de tout
   → Validation des décisions
   → Rapports et statistiques
   → Sauf : modifications libres

4. ENSEIGNANT
   → Saisie des notes
   → Gestion des présences
   → Suivi de sa classe
   → Consultation seulement (pas de suppression)

5. COMPTABLE
   → Gestion paiements
   → Rapports financiers
   → Comptabilité générale
   → Sauf : gestion pédagogique

6. SECRÉTAIRE
   → Support administratif
   → Documents administratifs
   → Consultation générale
   → Sauf : financier/pédagogique sensible

Pour modifier les droits :
→ Nécessite rôle ADMIN
→ Aller à Personnel → Droits d'accès
→ Attribuer ou retirer des permissions
